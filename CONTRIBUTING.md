# Contributing (EN)

Thank you for your interest in contributing to GreenCharge!

Please read this guide before submitting issues or pull requests. For Chinese instructions, see CONTRIBUTING_CN.md.

## Quick start

1. Fork the repo and clone to your machine
2. Install dependencies: `npm install`
3. Create a branch: `git checkout -b feature/your-feature-name`

## Pull Requests

When opening a PR, please use the repository Pull Request template (it will pre-fill when you click "New pull request").

If you need the template, see: [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md)

### Before submitting
- Rebase or merge latest main
- Run tests and linters
- Provide a clear description and link related issues

### PR checklist
- [ ] My changes follow the code style of this project
- [ ] I have added tests where applicable
- [ ] I have added documentation where necessary
- [ ] All tests pass

Thanks for contributing!
