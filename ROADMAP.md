# 🗺️ Roadmap

> **GreenCharge** future development plan.  
> Contributions on any of these items are welcome — check [CONTRIBUTING.md](CONTRIBUTING.md) to get started.
>
> 🟢 = Planned · 🔵 = In Progress · ✅ = Done

---

## 🔜 Short-term (1–3 months)

| Status | Feature | Description |
|--------|---------|-------------|
| 🟢 | **OCPP Protocol Support** | Add OCPP 1.6/2.0.1 integration for direct communication with real charging hardware |
| 🟢 | **Dark/Light Theme Toggle** | User preference persistence, follow system preference by default |
| 🟢 | **Unit Tests** | Jest + React Testing Library test coverage for core components and API routes |
| 🟢 | **Mobile Responsive Polish** | Further mobile UX optimization for the charging portal |
| 🟢 | **i18n Internationalization** | French, German, Japanese language support |
| 🟢 | **Docker Deployment** | Docker Compose for one-command local setup + cloud deployment |
| 🟢 | **API Rate Limiting** | Protect backend endpoints from abuse |
| 🟢 | **Real-time Notifications** | Charging session complete, price surge, station fault alerts |

---

## 🎯 Medium-term (3–6 months)

| Status | Feature | Description |
|--------|---------|-------------|
| 🟢 | **OpenStreetMap Integration** | Replace Leaflet tile layer with OSM for offline-friendly station mapping |
| 🟢 | **Real EV Data Integration** | Connect to public charging APIs (Open Charge Map, NREL) for real station data |
| 🟢 | **Payment Gateway** | Stripe / Alipay integration for real payment processing |
| 🟢 | **Fleet Management** | Multi-vehicle fleet dashboard with scheduling and cost optimization |
| 🟢 | **Carbon Credit Tracking** | Calculate and display CO₂ savings per session and per user |
| 🟢 | **Admin RBAC** | Role-based access control (super admin, operator, viewer) |
| 🟢 | **Email Reports** | Weekly/monthly automated email reports for station operators |
| 🟢 | **Webhook System** | Allow external services to subscribe to charging events |

---

## 🚀 Long-term (6–12 months)

| Status | Feature | Description |
|--------|---------|-------------|
| 🟢 | **AI Model Self-Learning** | Continuous model retraining based on real charging data |
| 🟢 | **Blockchain Settlement** | Smart contract-based V2G settlement for peer-to-peer energy trading |
| 🟢 | **Microgrid Management** | Local energy storage + solar + charger integrated optimization |
| 🟢 | **Mobile App** | React Native app for drivers (iOS + Android) |
| 🟢 | **Multi-tenant SaaS** | White-label platform for charging network operators |
| 🟢 | **Load Balancing AI** | ML-based grid load prediction and proactive station throttling |
| 🟢 | **OpenADR 2.0b** | Automated demand response protocol for utility integration |
| 🟢 | **Plug & Charge (ISO 15118)** | Zero-touch authentication at charging stations |
